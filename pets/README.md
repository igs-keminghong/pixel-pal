# 夥伴（角色包）

每個夥伴是 `pets/` 底下的一個資料夾，資料夾名稱就是夥伴的代號（小寫英文、數字、底線，例如 `fox`）。

```
pets/
├─ index.json        夥伴清單（選單順序，第一個是預設夥伴）
├─ _template/        新夥伴的範本
└─ fox/
   ├─ pet.json       名字、個性、被點時的動作、台詞
   ├─ idle.png       平常待機（定稿，其他四張照它畫）
   ├─ happy.png      被點、開心時
   ├─ sleep.png      晚上 11 點後睡覺
   ├─ alert.png      提醒行程時
   └─ blink.png      眨眼：和 idle.png 同尺寸，只有眼睛不同
```

## 新增夥伴

1. 複製 `_template` 資料夾，改名成新代號，放進 5 張圖。
2. 填好 `pet.json`。
3. 在 `index.json` 的 `pets` 清單加上新代號。
4. 執行 `python tools/check_pets.py`，全部通過再 `git push`。

不用改程式、不用動 Supabase。推播程式會直接讀網站上的 `pet.json`，約 5 分鐘內生效。

## 圖片規格

- PNG、透明背景；不要地面、影子、文字。
- 像素風、深棕色外框，大頭小身體；可以拿 `shiba/idle.png` 當風格參考。
- 五張圖的角色大小要一致；App 會依 `idle.png` 的高度自動縮放。
- `blink.png` 必須和 `idle.png` **同尺寸、同位置**，只換眼睛，不然眨眼會跳動。
- 必須是原創角色，或已取得作者同意。不能用動畫、遊戲裡的現成角色。

## pet.json 欄位

| 欄位 | 說明 |
|---|---|
| `label` | 種類，顯示在選單（例如「狐狸」） |
| `name` | 預設名字，玩家可以自己改 |
| `desc` | 一兩句個性介紹，顯示在更新公告的新夥伴卡片 |
| `tap` | 被點時的動作：`jump` 跳、`wiggle` 搖晃、`purr` 呼嚕、`rub` 蹭蹭、`huff` 哼一聲轉身、`hop2` 連跳兩下、`dance` 跳舞、`jingle` 搖鈴 |
| `scale` | 選填，顯示大小的倍率（0.5～2，預設 1）。全身圖或有道具（例如坐在椅子上）顯得太小時用，例如 `1.25` |
| `lying` | 哪些姿勢是躺著的（例如 `["sleep"]`），躺姿會用較寬的影子 |
| `lines` | App 首頁台詞，見下表 |
| `push` | 推播台詞：`hello` 打聲招呼、`remind` 明天有行程、`free` 明天沒行程 |

台詞可以用 `\n` 換行。可用的代入文字：

| 代入 | 意思 |
|---|---|
| `{first}` | 下一個或第一個行程，例如 `14:00「牙醫」` |
| `{n}` | 明天的行程數 |
| `{left}` | 今天還剩幾件事 |
| `{time}` | 提醒時間（只用在 `push.hello`） |
| `{name}` | 夥伴的名字 |

| `lines` 欄位 | 什麼時候出現 |
|---|---|
| `tap` | 被點時，隨機選一句（陣列） |
| `noCalendar` | 還沒連結 Google 日曆 |
| `todayFree` | 今天沒有行程 |
| `todayNext` | 今天還有好幾件事 |
| `todayLast` | 今天只剩一件事 |
| `tonightThenTomorrow` | 今晚還有行程、明天也有：接在「今晚還有……」後面 |
| `tonightThenFree` | 今晚還有行程、明天沒事 |
| `tomorrow` | 明天有行程 |
| `tomorrowFree` | 明天沒有行程 |

沒填的欄位會用通用台詞，不會出錯。
